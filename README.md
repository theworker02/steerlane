# steerlane

Steer identifiers and lane tokens for idempotent workflows.

**Site:** https://theworker02.github.io/steerlane/

## Install / run

```bash
git clone https://github.com/theworker02/steerlane.git
cd steerlane
node src/cli.js
node --test
```
